# ENG14-3271: Add optional return_url claim support to LTI 1.3 launch payload

## Acceptance Criteria

Given the LTI 1.3 launch payload configuration
When a provider/driver has the return_url flag enabled
Then the launch_presentation claim should include a return_url field in the payload

Given an existing provider without the return_url flag configured
When the LTI 1.3 launch is triggered
Then the launch payload should NOT include return_url (backward compatibility maintained)

Given an admin user accessing the Properties UI
When they navigate to the provider configuration
Then they should see a boolean toggle to enable/disable the return_url claim

Given the return_url flag is enabled for Pearson provider
When a student launches an LTI 1.3 activity to Pearson
Then Pearson should receive a valid launch_presentation.return_url in the JWT payload

Given any provider configuration
When the return_url field value is not a valid URL format
Then the system should reject the configuration with a validation error
